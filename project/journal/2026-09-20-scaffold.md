# Scaffold

Started an empty train project using selected infrastructure from low-poly-fire-truck:
strict TS/package conventions, loading shell, PWA registration, worker, stamping and worker
regressions. Renamed the cache namespace and replaced app branding/icons. No personal data,
source project's deployment linkage, generated art, or completed-game status was copied.

Built a provisional procedural train loop with shared geometry and instanced sleepers,
fixed-step driving, release-to-stop, pause/restart and interruption handling. Prepared a
mockup brief; simulator camera and final visual style remain open.

User correction: design mockups must come first, with child agents and approval before
further implementation/deployment. Stopped runtime work. Spawned three agents for eight
